核心能力

  • Agent 协作设计：把前台交流与后台执行分开，让用户持续补充目标和修改方向，不必等待一次长任务结束；用统一入口承接项目，避免用户手动管理多个对话窗口。
  • 上下文与记忆：将项目、任务、资料和完成结论绑定到具体场景；近期信息优先进入当前对话，长期资料按需展开，并区分已确认事实、用户推断和 AI 判断。
  • 过程可控与结果验收：把 Agent 的行动限制在明确工具和可理解的步骤内；关键外部动作先征得用户确认，重要结果保留过程记录，中断后能从最近任务节点继续。
  • 评测与迭代：设计端到端任务、代表样本、有真值与无真值机评、成对盲评及回归方案；同时关注采纳率、留存、转化和实际业务指标。

独立产品实践

独立完成产品设计、全栈开发与上线。三个产品分别验证同一个方向：让用户从「管理一堆对话」回到「表达意图、推进任务、验收结果」。

NowBuild.ai｜营销项目协作 Agent

www.nowbuild.ai｜代码 github.com/JackZhong1998/N0707

  • 解决的问题：营销工作通常同时包含调研、策略、渠道内容和后续反馈；逐个在不同对话中完成，背景容易散，用户也需要在多个窗口之间切换。
  • 产品化设计：用一个统一入口承接用户意图；后台把调研、策略、内容等工作交给不同方向处理，但对用户仍呈现同一个项目和同一套任务状态。
  • 协作体验：前台保持对话连续，后台任务可并行推进；长任务拆成可见节点，中断后从最近节点继续，用户仅在关键选择和结果验收时介入。
  • 可控与沉淀：每个结论尽量保留资料来源；已完成的项目、用户偏好和品牌规则进入长期记忆，减少下一次重复输入。

todoAgent｜任务上下文 Agent

www.todoagent.cc｜代码 github.com/JackZhong1998/todoagent

  • 解决的问题：普通待办只记录事项，通用对话又容易把目标、背景、约束和验收标准埋进聊天；任务换一次对话，用户就要重述一次。
  • 产品化设计：把目标、背景、约束、完成标准和相关材料绑定到每一条待办，让 Agent 先理解任务，再提出分工和下一步。
  • 人机分工：分析哪些步骤适合由 AI 完成、哪些需要用户判断；先给建议和依据，用户确认后再执行，而不是默认自动替用户做事。
  • 持续沉淀：完成后的任务更新为可复用的 SOP；相似任务下次出现时，直接参考已确认过的做法，让助手随使用更贴合用户。

VoiceMind｜实时语音任务协作

www.voicemind.cc｜代码 github.com/JackZhong1998/voicemind

  • 解决的问题：实时表达中，用户的思路在流动；如果每生成一段结果都打断对话，或把语音只当成转文字，就无法同时满足「继续说」和「开始做」。
  • 产品化设计：前台持续接收语音与新指令，实时整理为任务、要点和文档；后台逐项生成结果，用户可以随时插话、暂停或改方向。
  • 输出体验：语音内容转化为可编辑的思维导图、文档和下一步行动；结果与最新指令绑定，旧结果不会覆盖用户刚刚改变的方向。
  • 核心价值：把「说想法」与「把想法变成可用结果」放在同一连续体验中，而不是先转写、再复制到另一个工具。
